# Windows

![Bannière ECOCERT](https://ecocert.bts.loutik.fr/assets/banniere_ecocert.png)

---

Cette section regroupe l'ensemble des procédures d'installation, de configuration et d'exploitation liées à l'environnement **Microsoft Windows Server**. Vous y retrouverez :

* **Active Directory (AD DS)** : Installation et configuration de l'annuaire centralisé, gestion des utilisateurs, des groupes et des GPO.
* **LDAPS** : Sécurisation du protocole LDAP par TLS/SSL pour l'intégration avec GLPI.
* **Commun** : Procédures communes à tous les serveurs Windows (configuration réseau).
