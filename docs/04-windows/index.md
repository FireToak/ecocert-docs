Cette section regroupe l'ensemble des procédures d'installation, de configuration et d'exploitation liées à l'environnement Microsoft Windows Server. Vous y retrouverez les documentations techniques dédiées aux services d'infrastructure tels que la gestion centralisée des identités et des accès (Active Directory), les services d'adressage réseau (DHCP), ainsi que le déploiement du système de gestion de bases de données relationnelles SQL Server 2022.
